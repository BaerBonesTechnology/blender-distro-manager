Early preview of Blender Distro Manager: download Blender and Kitchen 3D builds, manage installed versions, and share compatible community add-ons across them.

Downloads:
- macOS Apple Silicon: extract the ZIP and open Blender Distro Manager.app.
- Windows x64: extract the entire ZIP and run Blender Distro Manager.exe.
- Linux x64: extract the tar.gz and run Blender Distro Manager. A desktop environment and Electron's system dependencies are required; installing Blender tar.xz packages also requires xz.

These are portable builds, not setup installers. SHA-256 checksum files accompany each download.

The macOS preview is ad-hoc signed, not Developer ID signed or notarized. Windows is unsigned. OS security warnings may prevent launching these early builds. Do not disable system-wide security protections.

The manager can execute installed third-party add-ons through Blender. Only install add-ons you trust. This independent project is not affiliated with the Blender Foundation.
